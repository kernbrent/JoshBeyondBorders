Change the Admin password

Your verified current password is reused from sign-in. Choose the new password, enter it again, and select Update password.

Use at least 8 characters, including lowercase, uppercase, a number, and a special character.

The password and decrypted workbook stay in this browser. Only the temporary random workbook key and encrypted credential are sent to the protected update service over HTTPS; the key is verified and immediately discarded.

One-click giving update

Sync PayPal donations

Checks PayPal, adds only new Josh Beyond Borders donations, updates the encrypted Excel workbook, and publishes the guitar giving total.

Only this campaign is included Item Title: Josh Beyond Borders Donation Item ID: BeyondBorders Withdrawals, transfers, refunds, reversals, other campaigns, and duplicate transaction IDs are ignored.
Leave this blank until the donation has actually been paid out to Josh.

PayPal can take up to about three hours to place a completed donation in transaction reports. If a very recent gift is missing, try the sync again later.
